📄 doc-intel-api

running on … ↗ open Dynatrace dashboard

A demo document-service. The exact same code runs on AWS Fargate and on an AWS Lambda Web Function — the badge shows which one served this page. It serves documents, summarizes them with Amazon Bedrock (Claude Sonnet), and every request is traced to Dynatrace. Use the panels below, then watch it all appear on the dashboard.

1Browse the library

Full-length public-domain books served by the API — hundreds of thousands of words each. Click one to open it (an I/O call to the datastore for its metadata).

loading…

2Summarize a whole book with AI

A single book is far larger than any model's context window, so Summarize runs map-reduce: it samples sections across the book, summarizes them with Amazon Bedrock (Claude Sonnet) in parallel, then streams one combined summary. Lots of concurrent, I/O-bound model calls — the Web Functions sweet spot.
